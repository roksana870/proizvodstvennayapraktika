# Task2.7 — Сумма с params

Задание 22, уровень 2.

Запуск из корня репозитория:

    dotnet run --project Task2.7

Результат проверенного запуска: [result.txt](result.txt).

В условии две одинаковые сигнатуры: params не отличает метод от int[]. Один params-метод поддерживает все три вызова; настоящая перегрузка сделана для IEnumerable<int>. Результаты: 6, 6, 0. Пустая сумма по условию равна 0, а не 6.
