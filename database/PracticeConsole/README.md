# Задания 28–30

Консольное приложение: .NET 9, Microsoft.Data.SqlClient 6.1.6.
[Пакет на NuGet](https://www.nuget.org/packages/Microsoft.Data.SqlClient/6.1.6).

Перед запуском нужна база Practice.db, созданная скриптом ../init.sql.
Не запускайте init.sql повторно, если хотите сохранить изменения в базе.

## Запуск

В PowerShell из корня репозитория:

    $env:PRACTICE_DB_CONNECTION = Read-Host 'Введите строку подключения к Practice.db'
    dotnet run --project database/PracticeConsole -- all

Строку подключения вводите только в переменную окружения, не сохраняйте в файлах репозитория.

Команды приложения:

- list — сотрудники и зарплаты (задание 28).
- add "Имя сотрудника" 50000.25 1 — добавить сотрудника в отдел 1 (задание 29).
- report — отчёт по отделам (задание 30).
- all — сотрудники и отчёт, без изменения данных; используется по умолчанию.
- demo — сохранённая вставка, SELECT-проверка и удаление демонстрационной записи.
- verify — проверки FK, отрицательной зарплаты, пустого отдела и пустых результатов. Изменения данных отменяются через ROLLBACK.

Пример:

    dotnet run --project database/PracticeConsole -- add "Новый сотрудник" 50000.25 1
    dotnet run --project database/PracticeConsole -- report

Коды завершения: 0 — успех; 1 — неверные аргументы или нет переменной окружения; 2 — ошибка SQL Server; 3 — ошибка проверки или состояния подключения.

Отрицательная зарплата и значения с более чем двумя десятичными знаками отклоняются.
Дубликаты имён разрешены исходной схемой. Ошибки уникальных ключей 2601/2627 и внешних ключей 547 обрабатываются отдельно.
В verify временно удаляются данные внутри транзакции, затем выполняется ROLLBACK. Этот режим предназначен для учебной базы.
